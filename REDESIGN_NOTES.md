# GDG Noida Neon Redesign

This version keeps the existing React/GSAP functionality but changes the visual system toward a disciplined neon-cyan developer aesthetic inspired by the supplied login/register reference.

Key changes:
- centered framed sections
- cyan neon border/glow language
- balanced max-width wrappers
- controlled hero typography
- safer badge 2-column layout
- consistent spacing and overflow control
- hover/focus interactions without moving whole layout containers

Run:
npm install
npm run dev
